1. What is Bootstrap and why is it useful for website design? Bootstrap is a popular front-end CSS framework used for designing responsive and mobile-first websites. It provides a collection of predefined CSS classes, components, and JavaScript plugins that help developers create attractive and professional websites quickly. Bootstrap reduces the need to write large amounts of custom CSS and ensures consistency in design across different browsers. Bootstrap is useful for website design because it saves development time, provides a responsive layout by default, and makes websites compatible with all screen sizes such as mobiles, tablets, and desktops. It also includes ready-made components like buttons, forms, navigation bars, and cards, which improve the overall user experience. 2. Explain the Bootstrap Grid System and how it helps create responsive layouts The Bootstrap Grid System is a 12-column layout system used to create responsive webpage structures. It is based on rows and columns. A webpage is divided into rows, and each row is further divided into up to 12 columns. These columns can be combined or resized according to screen size. Bootstrap provides responsive classes such as col-sm, col-md, col-lg, and col-xl which automatically adjust the layout for different devices. For example, content can appear in one column on mobile screens and multiple columns on larger screens. This grid system helps create flexible and responsive layouts without writing complex CSS, ensuring that the website looks good on all devices. 3. Cards Cards are flexible content containers used to display text, images, and links in a structured format. They are commonly used for product displays, profiles, and blog posts.
